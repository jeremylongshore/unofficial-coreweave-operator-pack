# Support

Start with the [README](README.md), [quality limits](QUALITY.md) and the affected
skill's references and blueprint. This is community support, with best-effort
responses and no guaranteed response time or production on-call service.

- [Report a bug](https://github.com/jeremylongshore/unofficial-coreweave-operator-pack/issues/new?template=bug_report.md)
  with the commit/version, command, expected result and a small synthetic reproduction.
- [Propose an improvement](https://github.com/jeremylongshore/unofficial-coreweave-operator-pack/issues/new?template=feature_request.md)
  with an operator problem and evidence of what is missing.
- Report vulnerabilities privately using [SECURITY.md](SECURITY.md).

Never attach raw production logs, credentials, customer identifiers or private
corpora. This project cannot resolve CoreWeave account, billing or capacity issues;
contact your provider through your normal support channel for those.
